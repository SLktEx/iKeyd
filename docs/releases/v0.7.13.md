This is a v0.x maintenance release from `main-v1`.

Changes since v0.7.12:

- Preserve physical key-release ownership when a legacy runtime output exception causes the Windows hook to pass an event through. A later remapped repeat can no longer swallow that physical key's release. Failed key-up recovery clears ownership for the next hold.
- Include PR #272: atomic modifier chords, partial-send cleanup, JIS physical identity replay, held-key release handling, and clipboard selection snapshots.
- Include PR #269: roman-only IME conversion mode is no longer treated as Japanese kana input when deciding Space/alphabet rollover.
- Add regression coverage for failed down/up recovery, repeat and release ordering, normal releases, and injected-event interleaving. Publish `SHA256SUMS` for the Windows ZIP and executable.

Validation limitation: actual WezTerm Space+A and Alt+Right behavior has **not been validated with physical input on the user's Windows PC**. Automated source tests and Windows CI do not establish that both reported symptoms are fixed. Issue #255 remains open for that validation.

Download either `iKeyd-win-x64.zip` or `iKeyd.exe`. Compare its SHA-256 with the matching filename in `SHA256SUMS` before use.
