# Compatibility inventory metadata

`coverage-rules.json` overlays known iKeyd/test coverage onto the legacy inventory generated by `tools/analyze-legacy-compatibility.py`.

Rules are applied in order and later matches override earlier fields. Keep rules conservative: `partial` or `unknown` is preferable to claiming a long-tail legacy branch is covered without direct evidence.

Exact per-feature exceptions can match a generated `id`; broader rules can match `kind`, `tag`, `textRegex`, `ownerRegex`, or `windowContextRegex`.
